React JWT Auth Boilerplate (Vite)

Quick start:

1) cd frontend
2) npm install
3) npm run dev

Environment:
Create a .env file at frontend/.env with:
VITE_API_BASE=http://localhost:5000

Notes:
- This is a minimal boilerplate. The layout is simple and uses CSS in src/index.css.
- API paths are examples; adapt to your backend.
